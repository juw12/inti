What you are looking at

    
The display with its windows, the keyboard, mouse and serial driver, the disk driver
    and the file server are ordinary programs. A window is a permission like any other: a
    program can draw in the window it opened and in no other. Each one holds only the permissions it was handed, and the kernel
    is the only code that runs with full control of the machine. When a driver crashes or
    stops answering, the supervisor replaces it, and programs that were waiting for it simply
    get their answer from the new one.

    
This is a research toy, not a replacement for the system you use every day. It has no
    network, keeps only a few small files, and runs on one processor. Files you save here
    last until you reload the page. The
    scorecard says
    plainly where mainstream systems are ahead.

    
The emulator is v86
    (BSD 2-Clause licence), which runs a virtual PC in WebAssembly. The disk image it boots is
    the same file the tests boot in QEMU.
