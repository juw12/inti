What you are looking at

    
The screen driver, the keyboard and serial driver and the file server are ordinary
    programs. Each one holds only the permissions it was handed when it started, and the kernel
    is the only code that runs with full control of the machine. When a driver crashes or
    stops answering, the supervisor replaces it, and programs that were waiting for it simply
    get their answer from the new one.

    
This is a research toy, not a replacement for the system you use every day. It has no
    network, no disk file system and runs on one processor. The
    scorecard says
    plainly where mainstream systems are ahead.

    
The emulator is v86
    (BSD 2-Clause licence), which runs a virtual PC in WebAssembly. The disk image it boots is
    the same file the tests boot in QEMU.
